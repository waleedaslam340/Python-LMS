# Python for Kids Mission Control 🐍🚀

An interactive web application designed to teach Python to children aged 8–12 through guided lessons and hands-on coding.

## 🌟 Features
- **Interactive Practice Board**: Run Python directly in the browser using Pyodide!
- **12-Week Curriculum**: From "Hello World" to building an "Emoji Chatbot".
- **Gamified UI**: Vibrant colors, simple language, and rewarding progress tracking.
- **Parent Dashboard**: Track your child's progress and get teaching tips.
- **Rubber Duck Debugging**: Encourages kids to solve problems by talking them out.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Supabase
Create a `.env.local` file and add your Supabase credentials:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to start the mission!

## 📚 Curriculum Highlights
- **Phase 1**: The Basics (Variables, Input, Print)
- **Phase 2**: Logic & Art (If/Else, Loops, Turtle Graphics)
- **Phase 3**: Advanced Fun (Lists, Functions, AI Chatbots)

## 🏗️ Technical Stack
- **Frontend**: Next.js (App Router), Vanilla CSS, Framer Motion, Lucide icons.
- **Python Engine**: Pyodide (v0.26.1).
- **Backend**: Supabase (PostgreSQL, Auth).
